Step 1 of 4

Import your auditorium

Use a floor plan of the room (PDF, PNG, JPEG or SVG) and Roomio finds the seats for you, or an auditorium file that already lists every seat (.json, or a .csv with columns seat,x,y,z).

Drop a file here, or choose a file
Floor plan: .pdf · .png · .jpg · .svg  ·  Seat list: .json · .csv
What goes in the file? 
{
  "format": "roomio-auditorium",
  "schemaVersion": 1,
  "name": "Main Auditorium",
  "units": "ft",
  "yAxis": "down",
  "stage": { "x": 0, "y": 0 },
  "seats": [
    { "id": "A-1-1", "section": "A", "row": 1, "seat": 1, "x": -12.5, "y": 20 },
    { "id": "A-1-2", "section": "A", "row": 1, "seat": 2, "x": -10.5, "y": 20 }
  ]
}

CSV: one seat per line — seat,x,y,z (z optional). Labels like A-12-4 are read as section A, row 12, seat 4. Optional extra columns: section,row,number. Full details are in the README.

  1. Optional: Seating area — drag a rectangle around the seats so Roomio only looks there (not in the lobby, stage or legend).
  2. Draw a box around one seat on the plan (drag). Roomio finds every seat drawn the same way, at any angle.
  3. Check the dots. Add / remove fixes misses; Stage moves the stage (row 1 is nearest it).
  4. Set the scale — the seat spacing below, or Measure any known distance.

Step 3 of 4

Connect to Smaart

In Smaart: Options → Preferences → API → turn on the API. If Smaart runs on this computer, keep the host as localhost.

You can skip this and connect later from the Smaart button. The password is stored encrypted in your system keychain, never in the venue file.
